# NATH_OS — Portfolio Website

A responsive, terminal-inspired personal portfolio for Nathanael, featuring AI, machine learning, NLP and software engineering projects.

## Preview locally
Open `index.html` in your browser. No build tools or dependencies required.

## Deploy to Vercel
1. Sign in at https://vercel.com with GitHub.
2. Select **Add New → Project** and import `ClemenGame/portfolio-website`.
3. Choose **Other** for Framework Preset (if asked).
4. Leave the Build Command blank and use the repository root (`./`) as the Root Directory.
5. Click **Deploy**.

Every future push to the default branch can trigger automatic deployment when Git integration is enabled.

## Before sharing
- Replace the LinkedIn placeholder in `index.html` with your actual profile.
- Add a contact email if desired.
- Add verified links to your individual projects.
- Check all project descriptions for accuracy.

Built as a static HTML/CSS/JavaScript site.
